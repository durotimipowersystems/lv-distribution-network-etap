## AI Layer – Fault Current Prediction

A dataset was generated by varying grid strength (MVAsc) and transformer impedance.

Observed behavior:
- Fault current increases with grid strength
- Fault current decreases significantly with transformer impedance

A predictive relationship was derived:

Fault Current ∝ Grid Strength / Impedance

This enables estimation of fault levels under unseen system conditions.
