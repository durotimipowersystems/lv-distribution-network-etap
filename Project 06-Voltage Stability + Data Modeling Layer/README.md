# Project 6: Voltage Drop Analysis & Data-Driven Fault Prediction

## 1. Objective
To analyze voltage drop in a low-voltage distribution system and develop a predictive model that estimates fault current based on system parameters.

---

## 2. System Description

- Source: Utility Grid (33 kV)
- Transformer: 1 MVA, 33/0.415 kV
- Bus Voltage: 415 V
- Feeders:
  - Feeder 1 → 0.2 MVA Load
  - Feeder 2 → 0.3 MVA Load
- Cable lengths varied to observe voltage drop effects

---

## 3. Load Flow Analysis

Load flow analysis was performed to evaluate voltage levels across the system.

### Key Observations

- Voltage decreases with increasing cable length
- Voltage drop is more severe on higher load feeders
- Example result:

| Location | Voltage (%) |
|----------|------------ |
| Bus16    | ~98%        |
| Load 1   | ~88%        |
| Load 2   | ~68%        |

### Engineering Insight

Voltage drop is primarily influenced by:

- Cable impedance (R + jX)
- Load current magnitude
- Distance from source

---

## 4. System Improvement Analysis

Two corrective strategies were tested:

### Case A — Load Reduction
- Reduced load demand
- Result: Significant voltage improvement (~87%)

### Case B — Transformer Upgrade
- Increased transformer capacity
- Result: Minimal voltage improvement (~70%)

### Conclusion

> Load reduction had a greater impact than transformer upgrade because voltage drop is dominated by feeder impedance, not transformer capacity.

---

## 5. Cable Sizing Impact

Cable size was increased from 16 mm² to 50 mm².

### Result:
- Voltage improved to >90% at load buses

### Interpretation:
- Larger cable size reduces resistance
- Lower resistance → lower voltage drop

## 7. Data Modeling (AI Layer)

A multi-variable regression model was developed using Excel:

### Insights:
- Fault current increases with grid strength
- Fault current decreases with higher transformer impedance
- Transformer impedance significantly limits fault level

---

## 8. Engineering Interpretation

This project demonstrates:

- The relationship between system strength and fault levels
- The dominant effect of impedance in limiting current
- The importance of cable sizing in voltage performance

---

## 9. Key Takeaways

- Voltage drop is driven more by feeder impedance than transformer size
- Cable sizing is critical in LV system design
- Fault current is influenced by both grid strength and impedance
- Data modeling can be used to predict system behavior

---
